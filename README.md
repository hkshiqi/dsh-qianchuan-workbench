# dsh-qianchuan-workbench · 千川投流工作台

> 给千川投流手的**决策工作台**——不是又一个报表，而是「现在该动哪条计划」。

装在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 里的侧边栏工作台：账户 / 计划 / 素材 / 直播间数据一屏看完，并直接给出可执行的操作建议。

## 安装

```sh
dsh plugin --profile web add dsh-qianchuan-workbench
```

装完重启 dsh web，侧边栏出现 **📊 千川工作台**。

## 你会得到

| 页签 | 内容 |
|---|---|
| **作战台** | 全账户消耗 / 净成交 / 净ROI vs 目标线、板块拆解、直播间实时 |
| **决策队列** | 按规则筛出「现在该动哪条计划」，每条带数据证据与推演 |
| **计划体检** | 计划级 ROI 排行，按消耗排序，异常置顶 |
| **直播间** | 在线人数、场观、观看→成交率、GPM、订单成本 |
| **素材** | 素材级消耗与 ROI 聚合 |
| **异常雷达** | 烧钱无转化、预算将尽、已达赔付线、数据过期 |
| **AI 建议** | 逐条计划给出建议 + 理由 + 把握度 |
| **设置** | 填写你自己的账号（aavid / CDP 端口 / 采集目录） |

## 第一次使用

插件**不预置任何账号数据**。装好后进入工作台 → **设置** 页签，填写：

- **aavid** —— 千川账户 ID（浏览器地址栏 `aavid=` 后面那串）
- **CDP 端口** —— 你的浏览器分身调试端口（默认 9222）
- **采集目录** —— 本机已有的采集产物目录，可留空
- **roomId / anchorId** —— 直播间大屏需要，可留空

保存后即可看到数据。

## 数据从哪来

- **凭证**：通过 CDP 连接你已登录的浏览器分身，**只读 cookie**，不打开页面、不抢焦点
- **数据（双源）**：
  1. 本机采集产物（如 `qc_data_cycle15_*/cycle_snapshot.json`）—— 全量、已归一化
  2. 平台实时接口（直播大屏）—— 秒级刷新
- **所有请求走纯 HTTP**，不使用浏览器渲染

> 采集目录是**可选**的。留空时插件只用实时接口，仍可看到直播间数据与异常雷达。

## 决策队列的规则

| 动作 | 触发条件 |
|---|---|
| 建议关闭 | 消耗 > ¥30 且 净ROI < 目标，**连续 2 轮**命中 |
| 建议加预算 | 净ROI 达标且预算将尽 |
| 建议复制放量 | 净ROI 显著超标（≥1.5 倍目标） |
| 重点观察 | 有消耗但零成交 |

**为什么要「连续 2 轮」**：消耗是实时的、成交是滞后回传的，单轮瞬时净ROI 会在「消耗先到、成交后到」的窗口里虚假偏低。两轮确认避免误杀计划。
